# C++ Object-Oriented Programming (OOP) Quick Notes 🚀

A structured collection of executable C++ code snippets created for quick revision of fundamental Object-Oriented Programming (OOP) concepts.

---

## 📌 Topics Covered

| File | Concept | Focus |
| :--- | :--- | :--- |
| `1.cpp` | **Classes & Objects** | Basic class structure, attributes, and instantiation |
| `2_Constructor.cpp` | **Constructors & Destructors** | Parameterized constructors, default constructors, memory lifecycle |
| `3_ObjPointer.cpp` | **Object Pointers** | Dynamic memory allocation (`new`/`delete`) and arrow operator (`->`) |
| `4_Private.cpp` | **Encapsulation** | Access modifiers (`private`, `public`) and Getters/Setters |
| `5_Inheritance.cpp` | **Inheritance** | Single, Multiple, and Multilevel class inheritance |
| `6_Overriding.cpp` | **Polymorphism** | Method overriding and virtual functions |
| `7_FriendFunc.cpp` | **Friend Functions** | Accessing private members using friend functions/classes |
| `8_AbstractClass.cpp` | **Abstraction** | Pure virtual functions and abstract base classes |

---

## 💻 How to Run Locally

### Prerequisites
* GCC / G++ Compiler (MinGW for Windows) installed and added to PATH.

### Compilation
Open your terminal in this directory and run any snippet:

```bash
# Compile
g++ 1.cpp -o 1.exe

# Run (Windows)
.\1.exe
